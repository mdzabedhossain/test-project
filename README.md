# NovaCart — Railway E-Commerce Demo

A lightweight responsive e-commerce storefront built with plain HTML/CSS/JavaScript and a tiny Node.js server. Designed to run on Railway with no external database or API keys required.

## Features
- Responsive storefront
- Product catalog
- Add-to-cart counter
- Demo cart notifications
- Promotional section
- `/health` endpoint
- Uses Railway's dynamic `PORT`

## Run locally
```bash
npm start
```
Then open `http://localhost:3000`.

## Deploy
Deploy the `main` branch to Railway. The start command is `npm start`.
